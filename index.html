01 — Fundamentos

Escolher uma fonte é escolher um tom de voz.

Tipografia é a arte de organizar letras para tornar a comunicação clara, legível e expressiva. Em HTML, os elementos dão estrutura ao conteúdo; no CSS, definimos como cada texto aparece.

02 — Famílias tipográficas

Quatro jeitos de contar uma história.

Passe o cursor pelos cartões — ou toque neles — para perceber como a personalidade muda mesmo quando a frase continua igual.

01Clássica

Elegância que atravessa o tempo.

Serifada

Possui pequenos prolongamentos nas letras. Transmite tradição e é muito usada em livros, editoriais e marcas refinadas.

font-family: Georgia, serif;
02Direta

Clareza para ideias modernas.

Sem serifa

Tem formas limpas e objetivas. Funciona muito bem em telas, interfaces, textos curtos e projetos contemporâneos.

font-family: Arial, sans-serif;
03Técnica

Cada caractere ocupa seu espaço.

Monoespaçada

Todas as letras têm a mesma largura. É associada a código, tecnologia, máquinas de escrever e dados.

font-family: Consolas, monospace;
04Expressiva

Feita para chamar atenção!

Display

Marcante e cheia de personalidade. Ideal para títulos, cartazes e destaques — mas deve ser usada com moderação.

font-family: Impact, fantasy;

03 — Hierarquia

Ajude o olhar a encontrar o caminho.

Uma página clara combina níveis de informação. O título chama, o subtítulo contextualiza e o corpo desenvolve a ideia sem cansar.

  1. ContrasteAltere tamanho, peso ou cor para diferenciar.
  2. RespiroUse espaço para separar e agrupar informações.
  3. ConsistênciaRepita padrões para facilitar a leitura.

Quantas fontes devo usar?

Duas costumam ser suficientes: uma com personalidade para os títulos e outra simples para os textos. Uma única família, variando pesos, também funciona muito bem.

Como criar uma lista segura no CSS?

Liste a fonte desejada e depois alternativas. Exemplo: font-family: Inter, Arial, sans-serif;. Se a primeira não existir, o navegador usa a próxima.

O que melhora a leitura?

Corpo com pelo menos 16px, bom contraste, linhas com cerca de 45 a 75 caracteres e espaçamento entre linhas por volta de 1.5 são ótimos pontos de partida.
